---# Module 3: Build Your First Astronomy AI

## Objective

In this module, you will train an Artificial Intelligence model capable of identifying different astronomical objects.

By the end of this module, your AI will be able to distinguish between:

* Galaxies
* Nebulae
* Stars

No programming is required.

---

## What is Teachable Machine?

Teachable Machine is a free machine learning platform developed by Google that allows anyone to create AI models directly in a web browser.

Instead of writing code, you train the model by providing examples.

Website:

https://teachablemachine.withgoogle.com/

---

## Step 1: Download the Dataset

Download the dataset below:

https://www.kaggle.com/datasets/abhikalpsrivastava15/space-images-category

After downloading:

1. Extract the ZIP file.
2. Open the dataset folder.
3. Locate the folders:

   * Galaxies
   * Nebulae
   * Stars

---

## Step 2: Open Teachable Machine

Go to:

https://teachablemachine.withgoogle.com/

Click:

Get Started → Image Project → Standard Image Model

---

## Step 3: Create Your Classes

Rename the classes as follows:

Class 1 → Galaxy

Class 2 → Nebula

Class 3 → Star

---

## Step 4: Upload Images

Upload images from the dataset folders.

Recommended:

* 50 Galaxy images
* 50 Nebula images
* 50 Star images

For better accuracy, use more images.

---

## Step 5: Train the AI

Click:

Train Model

Wait for the training process to finish.

The AI will automatically learn visual patterns from the images.

---

## Step 6: Test the Model

After training:

1. Click Preview.
2. Upload a new image.
3. Observe the prediction.

Questions:

* Was the prediction correct?
* Which class was easiest to recognize?
* Which class was most difficult?

Record your observations.
